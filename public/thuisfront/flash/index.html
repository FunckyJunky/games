HOME FRONT · PUT IT ON THE BOARD

For the ESP32-S3 board with the 1.47" screen (the same board as pocket.DOS). Use Chrome or Edge on a computer.

  1. Plug the board into this computer with USB.
  2. Press INSTALL and pick the board's port (USB JTAG / USB Serial, or COMx).
  3. When it is done, the board restarts. With no WiFi yet it makes the WiFi HOMEFRONT-XXXX: join it with your phone and pick your WiFi.

This browser can't talk to USB boards. Use Chrome or Edge on a computer. Open this page over https.

It doesn't connect? Hold the BOOT button, press and let go of RESET (or plug it in while holding BOOT), let go of BOOT, then try again.
This replaces what is on the board now (pocket.DOS too). The sketch is in the games repo at esp32/HomeFront.
