BOOT

Menu: tap = next, hold = play (or click a game). In a game: the button is everything. Hold 3 s, ESC or MENU = back. Keys: SPACE / ENTER / ↑ = the button.

WHAT IS THIS

pocket.DOS is a tiny game system for the ESP32-S3 board with the 1.47" colour LCD and one button. After its welcome screen it joins your WiFi. When it finds no WiFi it knows, it makes its own WiFi pocket.DOS: join it with your phone and a setup page opens, where you scan and pick your WiFi and can pair a Bluetooth keyboard or mouse. Online, the board loads the menu you see above from error.blue/pocket. Games you played are kept on the board, so they work without WiFi too.

Every game here is one small JavaScript file in /pocket/apps/, listed in apps.json. The board runs exactly the same file (with the Duktape JavaScript engine), so what plays here plays there.

MAKE AN APP

The pocket.DOS API (160 x 86 pixels, one button)

Define init(), update() and draw(); update + draw run 30 times a second. Write plain ES5 (var, function; no arrow functions or let) so the board understands it.

cls(c)clear the screen
pset(x,y,c)one pixel
rect(x,y,w,h,c) box(...)filled / outlined rectangle
line(x0,y0,x1,y1,c)a line
circ(x,y,r,c) ring(x,y,r,c)filled / outlined circle
text(s,x,y,c[,scale])5x7 letters, returns the width; textw(s[,scale]) measures
btn() btnp() btnr()button held / just pressed / just released
rnd(n) irnd(n)random 0..n / whole number 0..n-1
t() frame()seconds since start / frame number
save(k,n) load(k,def)keep a number (a high score) on the board
led(c)the board's colour light (0 = off)
exit() print(s)back to the menu / a line in the serial monitor
W H160, 86
colours0..15 = the palette below, or 0xRRGGBB

// a whole app
var x = 80, v = 0;
function update() { if (btnp()) v = -3; v += 0.2; x += v; if (x > 80) { x = 80; v = 0; } }
function draw() { cls(1); circ(80, x | 0, 4, 12); text('TAP!', 2, 2, 7); }
