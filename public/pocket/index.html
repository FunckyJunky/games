BOOT

Menu: tap = next, hold = open (or arrows + ENTER, or click an app). In an app the button is everything, SPACE / ENTER work too. Hold 3 s, ESC or MENU = back. NEON FLIGHT: the arrow keys tilt (on a phone: tilt the phone), SPACE = gas.

WHAT IS THIS

POCKET.DOS is a tiny ERROR-DOS for the ESP32-S3 board with the 1.47" colour LCD, one button and a motion sensor. After its DOS boot it joins your WiFi. When it finds no WiFi it knows, it makes its own WiFi pocket.DOS: join it with your phone and a setup page opens, where you pick your WiFi and can pair a Bluetooth keyboard or mouse. Online, the board loads its menu and apps from error.blue/pocket, the page you are on. Apps you used stay on the board and work without WiFi too.

The menu (menu.js) and every app are small JavaScript files listed in apps.json. The board runs exactly the same files (with the Duktape JavaScript engine), so what runs here runs there. ERROR-CHAT here and on the board is the same chat as ERROR-CHAT in ERROR-DOS.

MAKE AN APP

The pocket.DOS API (160 x 86 pixels, one button)

Define init(), update() and draw(); update + draw run 30 times a second. Write plain ES5 (var, function; no arrow functions or let) so the board understands it.

line(x0,y0,x1,y1,c)a line (any length, cut at the screen)

text(s,x,y,c[,scale])5x7 letters, returns the width; textw(s[,scale]) measures

// a whole app
var x = 80, v = 0;
function update() { if (btnp()) v = -3; v += 0.2; x += v; if (x > 80) { x = 80; v = 0; } }
function draw() { cls(0x031208); circ(80, x | 0, 4, 0x39ff7a); text('TAP!', 2, 2, 0x39ff7a); }
