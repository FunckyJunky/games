ERROR-CUBE · BACKUP & RESTORE

Saves everything on the cube's 16 MB flash to one file on this computer (firmware, settings, files), so you can always put it back exactly as it was. Use Chrome or Edge on a computer, with the cube plugged in by USB.

Close the Arduino IDE's Serial Monitor first (it keeps the port busy). The cube restarts when it's done. Takes about 2–5 minutes: don't unplug.

1 · ALLOW USB

Once per computer: pick the cube (COMx) in Chrome's little window and press Connect.

2 · BACKUP

3 · INSTALL ERROR-CUBE

Writes ERROR-CUBE ? onto the cube over USB.

RESTORE A BACKUP

Writes a backup file back onto the cube, over everything that's on it now.
